## 📖 Tentang Proyek

**Alfatih Digital Workspace** merupakan aplikasi web yang dirancang untuk membantu mahasiswa, profesional, freelancer, dan kreator digital dalam mengelola aset digital sekaligus membangun identitas profesional secara daring.

Platform ini hadir sebagai solusi yang menyatukan kebutuhan penyimpanan dokumen, pengelolaan profil profesional, serta publikasi portofolio dalam satu ruang kerja yang terstruktur dan mudah digunakan.

---

## ✨ Fitur Utama

### 📁 Manajemen File Digital

* Upload dan pengelolaan file
* Pembuatan folder terstruktur
* Pratinjau dokumen
* Berbagi file melalui tautan dan QR Code
* Navigasi file yang intuitif

### 👨‍💼 CV Builder

* Pengelolaan data diri
* Riwayat pendidikan
* Pengalaman organisasi dan pekerjaan
* Daftar keahlian
* Riwayat proyek dan pencapaian

### 🌐 Portfolio Builder

Mengubah data CV menjadi halaman portofolio profesional yang siap dibagikan kepada dosen, recruiter, perusahaan, maupun calon klien.

### 🏆 Direktori Talenta

Menyediakan wadah bagi pengguna untuk menampilkan profil profesional secara publik sehingga lebih mudah ditemukan dan dikenal.

### 🔒 Sistem Keamanan

* Login dan autentikasi pengguna
* Hak akses berdasarkan peran (Role-Based Access Control)
* Proteksi CSRF
* Pencatatan aktivitas pengguna
* Pengelolaan data yang lebih aman
